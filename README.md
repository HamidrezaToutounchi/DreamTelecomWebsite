# Dream Telecom Kurumsal Web Sitesi

Dream Telecom kurumsal kimliğini, 10 yıllık telekomünikasyon tecrübesini ve **Grandstream Networks** yetkili donanım portföyünü yansıtan modern, duyarlı (responsive) React kurumsal web uygulaması.

## 🚀 Teknolojiler
- **Kütüphane:** React 19
- **Derleyici / Build Tool:** Vite
- **Stil & Tasarım:** Tailwind CSS v4, Inter & Plus Jakarta Sans
- **İkonlar:** Lucide React
- **Harita:** Entegre Google Maps iframe

## 📂 Sayfa Yapısı & Mimarisi
- **Ana Sayfa:** Kurumsal profil, Grandstream öne çıkan çözümleri, telekom omurga telemetrisi.
- **Kurumsal:**
  - `Hakkımızda & Vizyon` (`#hakkimizda`): Şirket misyonu ve kurumsal geçmiş.
  - `Aktif Kurumsal Tecrübe` (`#aktif-tecrube`): 12 farklı sektörde 1.000+ kurumsal müşteri referansı.
  - `Sistem & Veri Güvenliği` (`#sistem-guvenlik`): Tier III Datacenter, Dark Fiber yedekliliği ve fiziksel güvenlik standartları.
  - `Banka Hesap Bilgileri` (`#banka-hesaplari`): Resmi Garanti BBVA, İş Bankası, TEB ve YKB IBAN'ları tek tıkla kopyalama özelliğiyle.
- **Hizmetlerimiz:**
  - `IP Sanal Santral (Bulut PBX)` (`#ip-sanal-santral`): Sıfır donanım maliyeti, sınırsız eşzamanlı hat ve gelişmiş IVR.
  - `SIP Trunk & Numara Taşıma` (`#sip-trunk`): 0850 ve coğrafi numaralar, %70 tasarruf ve SRTP/TLS şifreleme.
  - `Monites İzleme Yazılımı` (`#monites`): Türkiye'nin yerli bulut izleme yazılımı (Sippy, Asterisk, PBX, kamera ve sunucu izleme).
  - `CRM Çağrı Yönetimi` (`#crm`): Bulut Dream CRM, entegre IVR, pop-up müşteri kartı ve ses arşivi.
- **Grandstream Donanım Kataloğu:**
  - Birleşik İletişim (UCM6300 PBX serisi, GRP serisi IP telefonlar)
  - Ağ Çözümleri (Wi-Fi 7 / 6E AP'ler, Layer 3 PoE switchler)
  - Tümleşik Ağ ve PBX - GCC Serisi
- **Müşteri Referansları (`#referanslar`):** Teknoloji ortakları, sektörel başarı hikayeleri ve müşteri yorumları.
- **İletişim & Keşif (`#iletisim`):** Form, departman e-posta rehberi ve Google Maps Beylikdüzü merkez ofis haritası.

## 🛠️ Kurulum & Çalıştırma

Projeyi yerel ortamınızda çalıştırmak için:

```bash
# 1. Bağımlılıkları yükleyin
npm install

# 2. Geliştirici sunucusunu başlatın
npm run dev

# 3. Üretim (production) derlemesi alın
npm run build

# 4. Derlemeyi önizleyin
npm run preview
```
